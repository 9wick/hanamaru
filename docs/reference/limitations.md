# 提供範囲と保証の境界

## 契約を検証する範囲

対象・入力・観測・期待を定義し、用途に合わない組合せを型と実行時に拒否します。[UX/DX契約](../guides/testing-contracts.md)に従います。任意の述語や観測器の意味的な正しさを自動証明するものではありません。

## 型と実行

引数・戻り値・観測結果は対象から推論します。CLIはTypeScriptを変換して実行し、型検査は利用者のTypeScript環境で行います。型を経ない入力でも、不正な記述子や参照を実行受付で拒否します。

## ケースの独立性

ケースは他のケースの順序・実行有無に依存できません。環境は必要な外部状態の初期化と復元を提供します。資源を共有することと、ケース間で結果を引き継ぐことは別です。順序に意味のある操作は[flow](../guides/flow.md)へまとめます。

## blueprintの性質

定義は対象を実行せずに取得できます。関数や資源の参照を含むため、JSON往復による復元を保証しません。任意の関数内部を解析して、業務上の責任・純粋性・未評価の結果を自動決定しません。

## 観測と代替

実際の効果を観測し、観測不能を不在に変換しません。infraの代替は環境が許可した境界だけに限ります。呼び出しの記録から実際の効果を保証したとは扱いません。[期待と観測](api-expect.md)に従います。
